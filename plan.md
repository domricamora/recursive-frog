**Project:** Recursive Frog  
**Target market:** Aesthetics clinics in Cebu City, Philippines

**Document status:** Initial implementation specification  
**Source basis:** Recursive Frog clinic services offer PDF

---

## 1. Project Overview

Recursive Frog needs a professional, conversion-focused company website that explains its digital systems offering to aesthetics clinics.

The website should communicate three levels of service:

1. **Recursive 3** — Website
2. **Recursive 5** — Website + SaaS
3. **Recursive 7** — Website + SaaS + AI automation

The source material states that the exact package inclusions are still being finalized. Therefore, the website should support package content through editable data rather than hard-coding unconfirmed features or prices.

### Primary website goals

- Explain the problems Recursive Frog solves for clinics.
- Clearly communicate the Build → Automate → Scale model.
- Generate qualified consultation/demo inquiries.
- Explain the three service tiers.
- Demonstrate technical credibility through real projects.
- Build trust around ownership, communication, testing, security and responsible AI.
- Provide a foundation that can later connect to SaaS and automation products.

# 2. Target Audience

## Primary audience

Aesthetics clinics in Cebu City and surrounding areas.

## Typical problems

The website should directly address the problems identified in the source material:

- Inquiries getting buried in Messenger and Viber chats.
- Missed appointments.
- Lack of reminders or deposits.
- Patient history spread across notebooks and paper forms.
- Uncertainty about stock/inventory.
- Limited visibility into business numbers until month-end.
- Clients visiting once and not returning.

## Visitor intent

Visitors are expected to fall into three broad groups:

### A. Clinic owner exploring options

Needs a better website and booking experience.

### B. Growing clinic

Needs a website plus internal software/SaaS.

### C. Established clinic seeking automation

Needs software and administrative automation.

# 27. Recommended Technology Architecture

## Option A — Laravel-first

Recommended when the website is expected to become closely connected to the company's SaaS products.

### Backend

- Laravel
- PHP
- MySQL

### Frontend

- Blade
- Tailwind CSS
- Alpine.js where appropriate

### Admin

- Custom Laravel admin or a Laravel-compatible admin framework.

### Advantages

- Simple deployment.
- Shared backend conventions with existing Laravel work.
- Easy integration with future SaaS.
- Strong control over forms, leads and content.

---

## Option B — Laravel + React

Use React for highly interactive components while Laravel provides the application/backend layer.

Appropriate for:

- Interactive booking demonstrations.
- Advanced dashboards.
- More complex application interfaces.

Avoid adding React everywhere if normal content pages can be efficiently handled server-side.

# 32. Responsible AI Requirements

The source material explicitly positions AI as administrative assistance.

Implementation principle:

> **AI does admin only.**

The website must not imply that Recursive Frog's AI:

- Diagnoses patients.
- Recommends treatments.
- Replaces clinicians.
- Makes medical decisions.

For any future AI workflow:

```text
Input
  ↓
AI drafts/suggests
  ↓
Human reviews
  ↓
Human approves
  ↓
System applies action
```

No autonomous clinical decision-making should be presented as part of the offer.
